# pseudonymization-field-mapper

Generate a pseudonymization field map and implementation plan from a dataset schema.

## Run

```bash
python pseudonymization_field_mapper.py \
  --schema ../../samples/pseudonymization-field-mapper/schema.json \
  --out /tmp/pseudonymization_plan.json
```

## Sample input
- `../../samples/pseudonymization-field-mapper/schema.json`
