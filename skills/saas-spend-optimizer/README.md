# saas-spend-optimizer

Find unused seats, dead tools, duplicates, and upcoming renewals across your SaaS stack.

## Run

```bash
python optimize.py --subs ../../samples/saas-spend-optimizer/sample/subscriptions.csv --usage ../../samples/saas-spend-optimizer/sample/usage.csv
```

See [SKILL.md](./SKILL.md).
