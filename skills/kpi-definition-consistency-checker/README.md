# kpi-definition-consistency-checker

Check a KPI dictionary for conflicting definitions and missing metadata.

## Run

```bash
python kpi_definition_consistency_checker.py \
  --kpis ../../samples/kpi-definition-consistency-checker/kpis.json \
  --out /tmp/kpi_consistency_report.json
```

## Sample input
- `../../samples/kpi-definition-consistency-checker/kpis.json`
