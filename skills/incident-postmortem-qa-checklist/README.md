# incident-postmortem-qa-checklist

Convert an incident timeline into a postmortem QA checklist and gap report.

## Run

```bash
python incident_postmortem_qa_checklist.py \
  --timeline ../../samples/incident-postmortem-qa-checklist/timeline.json \
  --out /tmp/postmortem_checklist.json
```

## Sample input
- `../../samples/incident-postmortem-qa-checklist/timeline.json`
