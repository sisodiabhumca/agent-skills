# customer-interview-analyzer

Synthesize a folder of interview transcripts into themes, pain points, and JTBD signals.

## Run

```bash
python analyze.py --dir ../../samples/customer-interview-analyzer/sample_transcripts --question "Why is onboarding hard?"
```

See [SKILL.md](./SKILL.md).

## Sample data

Sample inputs for this skill live in `../../samples/customer-interview-analyzer/` (kept outside the skill folder so security scanners don't need to handle non-code data).
