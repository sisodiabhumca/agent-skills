# http-api-smoke-tester

Run a vendor-neutral HTTP API smoke test plan (requests + assertions) and emit a compact pass/fail report.

## Run

```bash
python http_api_smoke_tester.py \
  --plan ../../samples/http-api-smoke-tester/plan.json
```
