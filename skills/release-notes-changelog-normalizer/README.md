# release-notes-changelog-normalizer

Normalize raw release notes into a Keep a Changelog-style entry.

## Run

```bash
python release_notes_changelog_normalizer.py \
  --in ../../samples/release-notes-changelog-normalizer/release_notes.json \
  --out /tmp/changelog_entry.md
```

## Sample input
- `../../samples/release-notes-changelog-normalizer/release_notes.json`
