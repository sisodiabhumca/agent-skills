# accessibility-alt-text-auditor

Audit image `alt` text coverage and basic quality heuristics.

## Run

```bash
python accessibility_alt_text_auditor.py \
  --images ../../samples/accessibility-alt-text-auditor/images.json \
  --out /tmp/alt_audit.json
```

## Sample input
- `../../samples/accessibility-alt-text-auditor/images.json`
