# customer-journey-gap-analyzer

Analyze a CSV of funnel stages and drop-offs to identify the biggest customer journey gaps and suggest prioritized experiments (vendor-neutral).

## Run

```bash
python customer_journey_gap_analyzer.py \
  --input ../../samples/customer-journey-gap-analyzer/funnel.csv
```

## Sample
- Funnel CSV: `../../samples/customer-journey-gap-analyzer/funnel.csv`
