# privacy-policy-diff-summarizer

Diff two privacy policy texts and produce a vendor-neutral summary of materially changed sections and risk flags.

## Run

```bash
python privacy_policy_diff_summarizer.py \
  --old ../../samples/privacy-policy-diff-summarizer/policy_old.txt \
  --new ../../samples/privacy-policy-diff-summarizer/policy_new.txt
```

- Old: `../../samples/privacy-policy-diff-summarizer/policy_old.txt`
- New: `../../samples/privacy-policy-diff-summarizer/policy_new.txt`
